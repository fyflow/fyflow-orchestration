**2026-10-21, P39's W197 — measured on a map at 8,000 items, and kept apart from [Q735](q735.md).** A branch task whose
`needs` names a node OUTSIDE the map whose result holds the map's item list clones that list per read — once per
instance: the driver alone took **10.8 s at 8,000 items** on a scheduler double, **89% of it `structuredClone`**, where the
same flow reading a small value took 0.2 s (`test/fold/map-cost.test.ts` moved its items into a task of their own for
that reason). This is this question's cost, unchanged by P39; [Q735](q735.md) is the different cost of FINDING a
reference's output inside a map instance, whatever its size. Still deferred, still *nothing warns*.

**2026-10-22, P40's W199 — [Q735](q735.md) is RESOLVED** ([ADR 0124](../decisions/0124-a-reference-read-costs-its-answer.md)):
FINDING a reference's output now costs its answer, so what is left of a reference's cost inside a map is THIS question's —
the clone of what it names, per key per read. P40 (c) keeps it out of scope and deferred.

**2026-10-22, P41's W202 — RESOLVED by REMOVING the cost** ([ADR 0126](../decisions/0126-a-references-value-is-one-frozen-copy-shared-by-every-reader.md)):
fyflow-app reported the fetch-then-map flow's cost — 1.6 s / 160 MB at 1,000 items, 18.0 s / 800 MB at 4,000 on its Host —
which is this question's own *what would force it*. Every reader of one output is now handed ONE deep-frozen copy, made at
the first read, and `"$payload"` one per run. The driver alone, re-taken at W202's declaration and after it, node 24.20.0,
1,000 / 2,000 / 4,000 items: 529 / 1,993 / 15,475 ms and 178 / 468 / 1,448 MB → 33 / 53 / 91 ms and 5 / 11 / 15 MB. The
count is in the gate (`test/fold/reference-copy-cost.test.ts`, `outputsCache.copies` exact at 2,000 and 8,000 items).
**The decision that *nothing warns* stands** — there is nothing left to warn about. The price is two behaviour changes (an
inline worker's or a predicate's write into a referenced value throws) and a named gap (a `Map`, `Set`, `Date` or binary
value is shared writable), both ADR 0126's.
