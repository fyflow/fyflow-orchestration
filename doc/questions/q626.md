**Raised by [W165](../work-items/w165-pool-options-on-a-named-pool-instance.md)** (its conformity reader's F3).
[ADR 0099](../decisions/0099-a-named-instance-of-a-document-type-may-declare-its-own-pool-options.md) rule 1 counts the
built-in `Transform` as a DOCUMENT type — it is a declaration, `{}`, in `BUILT_IN_NODE_TYPES` — so a named instance of
it takes every pool option. **Measured**: `pools: { reshape: { type: 'Transform', pool: { residentGroups: ['gpu'],
idleTimeout: 1000 } } }` resolves, and the pool is built holding `gpu` for each worker's lifetime.

**What that contradicts.** [ADR 0075](../decisions/0075-a-node-that-only-transforms-is-a-built-in-type-with-no-inner-worker.md)
rule 3's closing note: a transform-only node *holds no resource group, and nothing a consumer writes changes that*; and
[Q457](q457.md)'s title, *reachable by NO road* — which now holds of `inline` and `groups` only. Neither P37 nor ADR
0099 decided it: (e)'s answer says *an instance of a DOCUMENT type*, and counting `Transform` as one was W165's
reading.

**The options.**

| | what it means |
|---|---|
| **Accept as stated** (the recommendation) | a consumer who wants a transform-only pool to hold a group — a rate on an expensive engine — has one road; ADR 0075's note is narrowed for good, and Q457 narrows to `inline` and `groups` |
| **Refuse `residentGroups` on a transform-only type's instance** | ADR 0075 rule 3's note stands; one more refusal with its own clause in the shape check, on both roads |
| **Refuse `pool` on it altogether** | the built-in's pool is the scheduler's default, as before v0.37; a second exception to ADR 0099 rule 1 |

**What we do meanwhile.** Accept it, as ADR 0099 consequence 5 states; the W165 suite pins the acceptance, so either
refusal is a visible test change.

**2026-10-16, ANSWERED at [P37](../plans/p37-a-runtime-is-its-registry.md)'s retro (h): accept as stated** — the
maintainer. A named instance of `Transform` keeps every pool option ADR 0099 admits, `residentGroups` included; ADR 0075
rule 3's note is narrowed for good, and [Q457](q457.md) narrows to `inline` and `groups`.
