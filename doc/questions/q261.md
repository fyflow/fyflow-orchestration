**Dated note, 2026-10-10, W152.** The npm half of this question is settled. The npm bundles
replace the envelope worker's URL with a `data:` URL on Node and a `Blob` URL in the browser
(`scripts/build.mjs`), so a bundle built from the npm `dist/browser` serves nothing beside itself for
the envelope worker. `npm run pack:smoke` P11 measures it in Chromium, threaded and inline. It stays
deferred for a bundle of the JSR SOURCE, which still resolves the worker beside the bundle. The
sentences that still describe the old npm behaviour are [Q580](q580.md).
