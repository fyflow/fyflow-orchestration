## Scope

**In**

1. **Filters**: `--where field=value` exact, `--where field~text` case-insensitive substring,
   repeatable and ANDed, over **any** front matter field of the record kind. `--search text` is a
   case-insensitive substring over every text field.
2. **Projection**: `--fields` prints only the named fields, in the order named. Defaults are the
   cheap ones — a list prints `id`, `status`, `title`; a single record prints its front matter and
   nothing derived. **`refs` and `body` are never printed unless named.**
3. **`icebox`**: left out of every list and every search unless `--where status=icebox` or
   `--include-icebox` is given. **By id it is returned**, because naming it is seeking it. When the
   exclusion hides any match, the output's last line says how many and how to see them.
4. **Exit codes are grep's.** 0: at least one record. 1: none — and the line names the filter or
   the id that found nothing, plus any hidden `icebox` count. **2: the reading is broken** — an
   unknown field in `--where` or `--fields`, an unparseable record, a kind that parses to zero
   records.
   *An unknown field is a 2 and never an empty result*: a misspelt field that silently matches
   nothing is `state.mjs`'s founding defect.
5. `refs` matches an id as a whole token (`Q17` does not match `Q170`), excludes `dev-dist/`,
   `node_modules/` and `.git/`, and prints paths with counts, never lines.
6. `adr --index` reproduces the columns the hand-kept index had, from front matter alone. **Before
   that section is deleted the two are compared and every difference is listed in the Record** —
   each is either a wrong hand-kept row or a wrong header, and the Record says which.

**Out**

- Writing anything. The lookup reads; `check:register` judges.
- Plans and work items as record kinds — P28 *Out*. `refs` still finds citations of their ids.
- Ranking or fuzzy search. Substring is predictable, and a ranked answer is a claim about relevance
  nobody checks.

### Decisions the plan did not make, each taken here

1. **The three stop-and-asks**, above: the self-test pattern, `X11` retired in ADR 0081, and a
   reader of the lookup's own held to `check-register`'s by AGREE.
2. **`term` matches the whole term cell, case-insensitively**: `term floor` is exit 1, and its line
   names `--where term~floor`, which finds `vacuity floor`. A substring match would be ranking.
   Positional words are JOINED, so `npm run term -- vacuity floor` is one term.
3. **`--format line`**: one record per line, values tab-separated in the projected order, no header;
   `\`, tab, newline and CR escaped as `\\ \t \n \r`, so a body is one line; `refs` prints
   `path:count` entries joined by `,`; a line opening `# ` is a note, never a record. **A lookup by
   id with no `--fields` prints each record's front matter as it stands in its file**, records
   separated by a blank line — a term's four fields in the same `key: value` shape.
4. **`--format json`** is one object, `{ kind, count, hidden-icebox, records }`, plus `none`,
   `not-found` and `not-shown` where they apply; `refs` is `[{ path, count }]`, `refs-count` a number.
5. **`refs`**: a Q, W, P or S id is an upper-case whole token — no letter, digit or underscore
   before, no digit after — so `Q17` is not in `Q170` or `XQ17`, and a range `Q17-Q19` cites its
   ends only. **An ADR is cited by** `ADR 0007` / `ADR-0007` in either case, the list forms
   `ADRs 0003 and 0004` (`check-register`'s `ADR_REF`), and its FILE NAME, which every link into it
   carries; **a bare `0007` is not**. `count` is the number of LINES citing it in that file, so a
   link whose text and path both name it is one; `refs-count` is the number of files. The record's
   own file is never a ref. The walk skips `.git`, `node_modules`, `dev-dist`, **`.claude`** (its
   `worktrees/` holds whole-tree copies — the conformity reader) and the other directories
   `.gitignore` names (`dist`, `test-results`, `playwright-report`, **`.vscode`**), and any file with a
   NUL byte. *(The first cut skipped neither `.claude` nor `.vscode`, while this line said it skipped
   what `.gitignore` names.)* A term's refs are its whole-word, case-insensitive lines — the predicate
   P28 measured *gate* with — so all three `gate` rows carry the same 274. `refs` with bare digits
   reads an ADR. **`refs` takes no `--where` and no `--search`** — exit 2 — since the fix round: the
   declaration gave it `--fields` and `--limit`, and the parser had accepted both filters, where
   `--where count=1` matched nothing (a number against a string) and `count~1` crashed at exit 1.
6. **`--search` reads the front matter fields only**, not `body`, which P28 decision 5 lists as
   derived — **a narrowing of *every text field***, as the conformity reader put it: an ADR's decision
   text is not searched. Taken here, not asked; a case now holds it. **`--where` on a derived field is
   a 2**, not a filter.
7. **`icebox` is shown by `--include-icebox`, by the exact `--where status=icebox`, or by id** —
   `--where status~ice` and `status~icebox` still hide it, and say so.
8. **`superseded-by` reads `ADR <newer> (<the older ADR's qualifier>)`, `; `-separated** —
   `ADR 0025 (rule 5)` on 0003. Nothing derives the inverse of `amends`; P28 names none.
9. **`--table` prints the ROWS** under `## Live` / `### <cluster>` and `## Resolved`, clusters in
   `doc/questions/README.md`'s order, rows by id; it takes no other option. **`--index`** renders
   `supersedes`, `amends` and the derived `superseded by` after the title, and `raised-by / item`
   with the item dropped when `raised-by` already names it (0004, 0055).
10. **Several ids may be named**; one not found beside one found is exit 0 with a `# not found:` note.
    **`--count` counts every match whatever `--limit` says**, and on no match prints the same `# no …`
    line a list does (in json, `none`) — the fix round, both readers.
11. **`refs S<N>` prints its count and a note that the namespace is shared** — [Q505](../questions/q505.md),
    raised here and RESOLVED by the maintainer here, 2026-10-05, from three priced options: a note
    (taken), a refusal with exit 2, or renaming one namespace (a plan's work, not an item's). Every
    upstream want S1-S10 is also a `check-source` clause id (S1-S16), so no token rule could separate
    them. In json the note is a `note` field.
12. **P28's exit artifact and its decision 5 disagree, and decision 5 is followed** — the conformity
    reader's note, unstated until then. The artifact says `npm run q -- Q17` prints *one record and
    every file citing it*; decision 5 says `refs` is never printed unless named. So `q -- Q17` prints
    the record (248 bytes) and `q -- Q17 --fields id,refs` the citing files (4,342 at the first
    measurement). A glossary cell's escaped `\|` reads as `|` since the fix round, so `term "a | b"`
    finds the term the adequacy reader could reach only as `a \| b`.

**Ceilings, stated.** `refs S<N>` counts upstream wants and `check-source` clauses together, and

repository name is counted as ours. `scripts/check-register.mjs`'s header still says a deleted ADR is
